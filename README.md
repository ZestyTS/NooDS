# NooDS - Wii U Autoboot Fork

ZestyTS's Wii U autoboot fork of [Hydr8gon/NooDS](https://github.com/Hydr8gon/NooDS).
The original emulator is by Hydr8gon and contributors.

This fork adds installed-content and SD autoboot configuration, per-title
settings, layout options, and startup diagnostics.

## Downloads

Use this fork's [Releases](https://github.com/ZestyTS/NooDS/releases) for
autoboot runtime downloads. If no release is listed, none has been published
yet. GitHub's Source code ZIP is not a ready-to-use runtime.

Select `noods.rpx` in UInjectForge to build a NooDS-based installable.
Use `noods.wuhb` for standalone SD/homebrew launch.
